# j&m. — website

Next.js 16 (App Router, Cache Components), React 19, Tailwind v4, next-intl (pt-PT), Motion + Lenis.

## Comandos

- `pnpm dev` — desenvolvimento
- `pnpm check` / `pnpm lint` / `pnpm typecheck` / `pnpm test` — qualidade
- `pnpm build` — produção

## Antes de publicar

substituir os placeholders de fotografia (equipa, antes/depois) e validar as minutas legais com um jurista.
